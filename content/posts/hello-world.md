欢迎来到我的博客！这是使用 **Nuxt 4 + @nuxt/content** 搭建的静态博客，部署在 GitHub Pages 上。

## 特性

- 暗色主题
- Markdown 写作
- 自动生成静态站点
- GitHub Actions 自动部署

## 代码示例

```ts
const greet = (name: string) => `Hello, ${name}!`
console.log(greet('World'))
```
